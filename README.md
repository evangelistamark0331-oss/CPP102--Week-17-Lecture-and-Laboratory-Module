Project Description: SmartTemp is a python program that simulates a device-temperature monitoring system. It stores temperature readings in a list and classifies each reading as Normal , Warning, Critical. It also calculates a numerical summary and determines the overall device status

Features

1. Display all stored temperature readings with their record numbers
2. Add a new temperature reading from 0 to 100
3. Classify each reading using the required temperature rules
4. Calculate the total readings, average, highest, and lowest temperature
5. Count Normal, Warning, and Critical readings

Temperature Classification Rules

1. Below 30C: Normal
2. 30C to 35C, inclusive: Warning
3. Above 35C: Critical

Requirements

1. Python 3
2. No external packages required

How to Run

1. Save the Python code as device_monitor.py
2. Press run
3. The output will be visible in terminal
4. Then select option 1 to 5
